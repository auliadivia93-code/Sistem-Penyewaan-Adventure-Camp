### Deskripsi Singkat Program
Program ini merupakan aplikasi berbasis console (CLI) menggunakan bahasa pemrograman C untuk mengotomatisasi pencatatan transaksi sewa alat camping di Adventure Camp. Program dapat menghitung subtotal, memberikan diskon otomatis berdasarkan lama sewa, serta menyimpan riwayat transaksi secara terstruktur.
